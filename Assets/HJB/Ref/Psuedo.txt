-------------------------------------------------------------
1. HELPER FUNCTIONS
-------------------------------------------------------------
function SpeedFromSlope(slope):
return base_speed * exp(-3.5 * abs(slope + 0.05)) # โมเดล Tobler
function FatigueIncrease(slope, time_step):
return fatigue_rate_time * time_step + fatigue_rate_elev * abs(slope)
function RecoverFatigue(type, f):
if type == MAIN_CAMP:
return f*(1 - recovery_maincamp) # ลดความเหนื่อยตามอัตราฟื้นตัว
if type == SHELTER:
return f*(1 - recovery_shelter)
return f
function LocalCost(x, y, slope, λ):
risk_term = risk_map(x,y) * c_risk # ค่าความเสี่ยงของพื้นที่
penalty_term = λ * fatigue(x,y) # ค่า penalty จาก fatigue[TS5.1][TS5.2]
return base_cost(x,y) + risk_term + penalty_term
-------------------------------------------------------------
2. SEMI-LAGRANGIAN UPDATE (HJB)
-------------------------------------------------------------
function UpdateSL(x,y, λ):
best_value = T(x,y)
best_fatigue = fatigue(x,y)
for dir in 1..M:
    # unit vector ของทิศทางนั้น
    (dx, dy) = direction_unit(dir)

    # จุดที่ characteristic ยิงไปตก
    x2 = x + dx*Δs
    y2 = y + dy*Δs
    if outside_domain(x2,y2): continue

    # ค่าแทรกเพื่ออ่านจากช่องที่ไม่ตรงกริดพอดี
    slope2 = slope(x2,y2)
    T2 = Interp(T, x2,y2)

    # ความเร็วและเวลาเดินช่วงนี้
    v = SpeedFromSlope(slope2)
    travel_time = Δs / v

    # อัปเดตค่า fatigue
    f_local = fatigue(x,y) + FatigueIncrease(slope2, travel_time)

    # ถ้าเหนื่อยเกิน limit → เพิ่มเวลาเดินเป็นบทลงโทษแบบ soft
    if f_local > fatigue_limit:
        travel_time += (f_local - fatigue_limit)*5.0

    # ต้นทุนรวมของช่วงนี้ (พื้นฐาน + เสี่ยง + penalty)
    c_local = LocalCost(x,y, slope2, λ)

    # สูตร semi-Lagrangian: ค่าในเซลล์ = cost local + ค่าอนาคต
    candidate = c_local * travel_time + T2

    # เลือกทิศที่ต้นทุนต่ำที่สุด
    if candidate < best_value:
        best_value = candidate
        best_fatigue = f_local

return best_value, best_fatigue
-------------------------------------------------------------
3. MAIN LOOP + PENALTY SEQUENCE
-------------------------------------------------------------
for λ in penalty_lambda_sequence: # รันซ้ำโดยเพิ่ม penalty ถ้า fatigue ยังสูง
iter = 0
converged = false

while iter < max_iter:
    diff = 0

    # Gauss-Seidel sweep (อัปเดตแบบไล่เรียง ทำให้ลู่เร็วขึ้น)
    for each cell (x,y) in traversal_order:

        oldT = T(x,y)
        oldF = fatigue(x,y)

        newT, newF = UpdateSL(x,y, λ)

        # ถ้าเดินมาถึงแคมป์/ที่พัก → ลดความเหนื่อยตามชนิดของสถานที่
        if isMainCamp(x,y):
            newF = RecoverFatigue(MAIN_CAMP, newF)
        elif isShelter(x,y):
            newF = RecoverFatigue(SHELTER, newF)

        T(x,y) = newT
        fatigue(x,y) = newF

        diff = max(diff, abs(newT - oldT))

    # ถ้าเปลี่ยนแปลงน้อยกว่า tol → ถือว่าลู่แล้ว
    if diff < tol:
        converged = true
        break

    iter += 1

# ตรวจว่าทางที่ได้ยังคงความเหนื่อยไม่เกินกำหนดหรือไม่
if CheckFatigueFeasible(start, goal, T, fatigue):
    break      # ถ้าทางดีแล้ว ก็ไม่ต้องเพิ่ม λ อีก
-------------------------------------------------------------
4. BACKTRACK FINAL PATH
-------------------------------------------------------------
path = []
p = start
while p != goal:
best_next = None
best_val = +∞
for dir in 1..M:
    (dx,dy)=direction_unit(dir)
    x2 = p.x + dx*Δs
    y2 = p.y + dy*Δs
    if outside_domain(x2,y2): continue

    val = T(x2,y2)
    if val < best_val:
        best_val = val
        best_next = (x2,y2)

path.append(best_next)
p = best_next
return path

 
Tobler's Hiking Function (Tobler’s model)
คือ สมการประเมินความเร็วในการเดินตามความชันของภูมิประเทศ (slope) ที่ใช้บ่อยมากในงานทำ cost surface หรือ least-cost path.
มันเป็นฟังก์ชันเชิงประจักษ์ที่นักภูมิศาสตร์ Waldo Tobler สร้างขึ้นจากข้อมูลการเดินจริงของมนุษย์
________________________________________
⭐ Tobler’s Hiking Function
สมการคือ:
V=6×e^(-3.5∣s+0.05∣)

โดยที่
	V= ความเร็วการเดิน (กม./ชม.)
	s= slope (ความชัน) = ความสูงต่าง / ระยะทางแนวนอน
________________________________________
⭐ สรุปพฤติกรรมของโมเดล
	เดินเร็วสุดตอนลงเนินเล็กน้อย (≈ –5° → ความชัน –0.05)
	ชันมากความเร็วลดลงรวดเร็ว
	ขึ้นชันเร็วลดลงเร็วกว่า
	ลงชันมากก็เดินช้าลงเพราะต้องเบรก/ทรงตัว
ภาพรวมแบบ intuitive:
ชนิดพื้นที่	Slope	ความเร็วโดยประมาณ
ทางราบ	0	~5.0–5.5 km/h
ลงนิดๆ (–5°)	–0.05	~6 km/h (สูงสุด)
ชัน 20°	0.36	ช้ามาก
ลงชันมาก (–30°)	–0.58	ช้ามาก
________________________________________
⭐ ทำไมใช้ในโมเดลวางเส้นทาง (HJB / shortest path)?
เพราะต้องการ คำนวณค่าสปีด (หรือ cost per meter) ของแต่ละ cell ใน DEM
และ Tobler ให้ speed ที่สัมพันธ์กับ slope อย่างสมจริงทางกายภาพของคนเดินจริง
ใช้ใน HJB แบบนี้:
V(x)="Tobler"(slope(x))

แล้วใช้คำนวณ cost ต่อ cell:
cost=Δx/(V(x)) "(เวลาเดิน)"

⭐ สรุปง่ายสุด
Tobler = “สูตรคำนวนความเร็วการเดินตามความชัน”
ใช้เพื่อให้เส้นทางที่คำนวณออกมา สมจริง → ไม่วิ่งลงหน้าผา/ปีนเขาชันแบบเร็วผิดจริง

กำหนด slope > 40° เป็น inaccessible without climbing aids
-Langmuir, E. (2013). “Mountaincraft and Leadership.” 4th ed., The Scottish Mountain Training Board.
ระบุว่า “non-technical scrambles” คือพื้นชัน 30–40°, หลังจากนั้นถือว่า “technical climb” ต้องใช้อุปกรณ์

-----------------------------------------
STEP 1 — สร้าง Node Graph + Buffer Zone
-----------------------------------------
nodes ← []

for ทุก cell ใน DEM แบบ subsample ทุก 200 m:
    if inside_buffer(cell, width = 200 m):
         nodes.add(cell)
buffer หมายถึง:
เฉพาะจุดใน DEM ที่อยู่ภายใน “เส้นทางที่เป็นไปได้” เช่น แถว ๆ ridge / valley line ไม่คำนวณทั่วทั้ง 2000×2000 m ในครั้งเดียว → ลดงานลง 90%

-----------------------------------------
STEP 2 — คำนวณ gradient ของ DEM
-----------------------------------------
css
Copy code
for ทุก node i:
    ∂E/∂x(i) = (E(i+Δgrid,x) - E(i-Δgrid,x)) / (2Δgrid)
    ∂E/∂y(i) = (E(i+Δgrid,y) - E(i-Δgrid,y)) / (2Δgrid)
    gradE(i) = (∂E/∂x, ∂E/∂y)
-----------------------------------------
STEP 3 — Precompute direction speeds
-----------------------------------------
css
Copy code
for node i:
    for ทุกทิศทาง θ:
        s = (cosθ, sinθ)
        S = dot(s, gradE(i))

        if S > S_up_max OR S < -S_down_max:
            Veff(i,θ) = 0
        else:
            risk   = compute_risk(i)
            Veff(i,θ) = (V(S) * risk) / α(i)
-----------------------------------------
STEP 4 — Semi-Lagrangian HJB Solve
-----------------------------------------
Initialize:
for ทุก node:     T(node) = +∞
T(start) = 0
Iterative update (Gauss–Seidel style):

repeat until converged:
    for node i:
        T_new = +∞
        
        for ทุกทิศทาง θ:
            # 1. เดินจาก node i ไปตำแหน่งย้อนทิศ
            x_prev = i - Δnode * s(θ)

            if x_prev อยู่ใน nodes:
                cost = Δnode / Veff(x_prev,θ)   # เวลาเดินระหว่างสองจุด
                T_new = min(T_new, T(x_prev) + cost)

        T(i) = T_new
เหตุผลที่ไม่เกิด artifact:
Semi-Lagrangian ใช้ค่า interpolated จาก “ตำแหน่งก่อนหน้า”
→ ไม่ขึ้นกับ orientation grid → ไม่มี staircase pattern
